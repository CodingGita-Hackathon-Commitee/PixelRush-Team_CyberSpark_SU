# 🍱 TiffinBox

A modern and responsive **Tiffin Meal Subscription Web Application** designed to help users manage their daily meals, subscriptions, meal changes, skipped meals, and payment history.

The project focuses on a clean, simple, and user-friendly interface for managing a monthly tiffin subscription.

---

## 📌 Features

- 🏠 **Home Dashboard**
  - Personalized greeting
  - Today's delivery information
  - Current subscription status
  - Meals remaining
  - Weekly meal schedule

- 🍛 **Weekly Menu**
  - View meals planned for the week
  - Check daily meal details

- 🔄 **Change Meal**
  - Select a different meal for today's delivery
  - Selected meal automatically updates on the Home page

- ⏭️ **Skip Meal**
  - Skip today's meal
  - Manage skipped meals

- 💳 **Payment History**
  - View previous payments
  - Check payment and billing information

- 📋 **Subscription Management**
  - View current plan
  - Track remaining meals
  - Manage subscription

- 📱 **Responsive Design**
  - Works on desktop, tablet, and mobile screens

---

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**
- **LocalStorage**

No external frameworks or libraries are required.
